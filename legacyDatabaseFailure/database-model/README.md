# Database Model

This folder contains visual documentation of the database structure used in the legacy operational system.<br>
It includes both a representation of the current-state structure and a proposed future-state model intended to support discussions with IT about replacement or redesign.<br>
The goal was to move from informal verbal explanation to a clearer structural representation of business requirements.<br>

## Practical use after the incident

Although the broader redesign effort was put on hold, the graphical model continued to be useful in practice.

Once partial access to the legacy database was restored, through  a 32-bit Office installation, I used the database information with additional meta data layered onto the model to accelerate case research and information gathering.<br>
In practice the model became a estruture for navigating legacy records more effeciently, especially where the original system remained limited or incomplete.<br>

This mattered because the artifact moved beyond its original purpose as a redesign aid and became a practical support tool for day to day operational retrieval and orientation<br>
